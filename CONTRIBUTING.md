# Contributing to OptiFlow Twin

Thank you for your interest in contributing to OptiFlow Twin!

Contributions, bug reports, feature suggestions, and improvements are welcome.

## Getting Started

1. Fork the repository.
2. Clone your fork:

   ```bash
   git clone https://github.com/YOUR_USERNAME/OptiFlow-Twin.git
   cd OptiFlow-Twin
   ```

3. Create and activate a virtual environment.
4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the application:

   ```bash
   streamlit run app.py
   ```

## Development Guidelines

- Keep code modular and readable.
- Follow existing project conventions.
- Add tests for new functionality.
- Avoid committing generated files, virtual environments, or secrets.
- Update documentation when changing application behavior.

## Running Tests

Before submitting changes, run:

```bash
pytest -v
```

Ensure all tests pass.

## Submitting Changes

1. Create a feature branch.
2. Implement and test your changes.
3. Commit your changes with a descriptive message.
4. Push your branch.
5. Open a Pull Request describing your changes.

## Reporting Issues

When reporting a bug, include:

- A clear description of the problem.
- Steps to reproduce it.
- Expected and actual behavior.
- Relevant error messages or screenshots.

Thank you for helping improve OptiFlow Twin!
